# Каталог самостоятельных проектов агентов

Статус: проектная документация / подготовка знаний. Реализация агентов отложена до создания и стабилизации приложений GLAFIRA Android и Windows Desktop и готовности Core/Bridge.

## Принятое организационное решение владельца

Каждый специализированный агент ведётся как самостоятельный проект с отдельным паспортом, базой знаний, функциями, ограничениями, тарифами, профилем, голосом, аватаром, версиями и критериями приёмки. Проекты не запускаются в производство и не подключаются к пользовательским чатам до отдельного этапа после создания приложений.

Пока разрешено: структурировать знания, писать спецификации, проверять источники, готовить синтетические тестовые примеры, фиксировать риски и зависимости. Не разрешено: запускать агентов как готовые продукты, подключать платные источники/API, списывать средства, включать автоматические действия или заявлять о готовности.

## Общий стандарт каждого проекта

1. Цель, целевая аудитория, сценарии и границы ответственности.
2. Каталог функций с разделением по тарифам и статусу (идея / описано / реализовано / проверено).
3. База знаний: источники, дата проверки, юрисдикция/регион, права использования, достоверность и история изменений.
4. Инструменты отдельно от моделей; бесплатные и локальные варианты — приоритет.
5. Профиль: имя, описание, текущий тариф, доступные функции, предупреждения, голос, аватар и аудиопредставление.
6. Безопасность, приватность, согласия, хранение данных, удаление и аудит.
7. Контракты GLAFIRA Core, Bridge и межплатформенного интерфейса.
8. Версионирование, тесты, критерии приёмки и план отключения/отката.
9. Не обучать базовую модель на пользовательских персональных данных; использовать retrieval, инструкции, схемы и одобренные примеры.

## Зависимости и порядок

Сначала создаются приложения Android и Windows Desktop и основные механизмы Core/Bridge. Пока это не завершено, проекты агентов остаются документальными пакетами знаний. После готовности платформы владелец отдельно утверждает очередность включения каждого агента.

## Общая модель тарифного расширения

Тариф агента задаёт временное право на конкретный набор возможностей. Оплата не должна скачивать произвольный исполняемый код. После подтверждения оплаты GLAFIRA Mother выпускает адресное подписанное расширение entitlement/capability manifest и, если нужно, подписанный пакет контента/инструментов. Core проверяет подпись, получателя, проект, тариф, срок и разрешения. Истечение срока отключает платные возможности, но не удаляет данные пользователя и не блокирует бесплатный базовый режим.

Подробная схема: `AGENT_VOICE_AVATAR_AND_DAILY_ENTITLEMENTS.md`; интеграция с Token: `../TOKEN/AGENT_DAILY_TARIFFS_AND_PERSONAL_UPDATES.md`.
