# Проект: Банкир

Project ID: `banker`  
Статус: новый отдельный проект, первоначальная спецификация.

## Назначение

Финансовый навигатор для личного и малого бизнеса: бюджетирование, анализ денежных потоков, планирование платежей, сравнение финансовых продуктов и объяснение финансовых документов. Не хранит банковские пароли и не распоряжается деньгами пользователя.

## База знаний

1. Основы учёта доходов/расходов, cash flow и бюджетирования.
2. Финансовая отчётность малого бизнеса и управленческие показатели.
3. Банковские продукты, комиссии, проценты и условия договоров с датой и страной.
4. Налоговые и регуляторные источники — только с указанием юрисдикции; юридические выводы передавать Юристу.
5. Кредитная нагрузка, сценарное планирование и оценка чувствительности без обещаний доходности.
6. Глоссарий финансовых терминов и проверочные задачи.

## Границы

Не является банком, брокером, аудитором или лицензированным инвестиционным консультантом. Не инициирует переводы, кредиты, сделки и инвестиции. Не гарантирует доходность и не скрывает риски. Для расчётов указывать допущения, комиссии, налоги, инфляцию и дату исходных данных.

## Тарифная модель

Бесплатно: объяснение документов, базовый бюджет и ручные расчёты. Возможные расширения: сценарии бизнеса, анализ загруженных выписок, дополнительные отчёты и интеграции — только после privacy review, разрешения источников и проверки тарифного entitlement. Никаких платных API по умолчанию.

## Подготовка до приложений

Создать словарь, шаблоны бюджета, синтетические примеры выписок, набор тестовых расчётов, перечень официальных источников по странам. Не подключать реальные банковские аккаунты и не хранить секреты.
