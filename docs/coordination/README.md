# Multi-agent coordination records

- [Participant template](PARTICIPANT_TEMPLATE.md): copy it to `participants/<unique-id>.md` when an invited AI collaborator joins.
- Each participant updates only their own record. Do not edit another participant's progress file.
- The repository-root [GLAFIRA_COORDINATION.md](../../GLAFIRA_COORDINATION.md) is the mandatory shared instruction entrypoint and is maintained by the central coordinator.
- GitHub issues and PRs remain the canonical record of code changes, review and CI evidence.
