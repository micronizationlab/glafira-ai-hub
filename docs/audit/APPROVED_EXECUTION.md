# Согласованный аудит: выполнение и зависимости

Исходный файл: `GLAFIRA_Audit_Register_2026-11-20.xlsx`; SHA-256 `1fa8031b1c2cebb928b08afa1f0d2d73a6fab934998331482903c09520677e34`. Все 40 решений — «Принять». База реализации: `c2d4ca36efd3a52a5cc3bde97969b2fb0a03e1cc`.

## Правила прохождения

Сначала реализуются и проверяются 40 исходных пунктов. Затем утверждается по результатам регрессии рабочая версия цикла 1 из 150 изменений. Номер шага не является доказательством выполнения. `planned`, `partial` и ожидание CI не означают «готово».

После завершения цикла 1 выполняется полный прогон Android JVM/APK/emulator, Desktop JVM, Windows Hub/UI/Agent, Swift package/app build, contracts и реальных межустройственных сценариев. Выявленные ошибки исправляются до перехода. Вторые 150 пунктов формируются из фактических результатов, после чего проходят тот же порядок. Цикл 2 пока не создан и не запущен.

Порядок слияния текущих изменений: #203 → #204; перед слиянием следующая ветка сверяется с обновлённой main. Старые #54/#56/#57/#58/#62/#64 нельзя сливать целыми стеками. Из #193 перенесён UI/status слой. #140 не является основанием превращать Android в авторитетный сервер.

Релизная подпись, реальные Face ID/биометрия, облачный round-trip и сеть нескольких устройств требуют соответствующих credentials/устройств. Для Mother/ledger/VPN исходная документация оставляет неутверждёнными выпуск токенов, тарифы и инфраструктуру; этот пакет нельзя объявлять завершённым настройками-заглушками.
